# 대출 실행 및 상환 프로젝트

## 1. 프로젝트 개요

> 📄 **상세 내용**: [[1] 프로젝트 개요](https://loan-project.tistory.com/19)

전체 대출 프로세스 중 **대출 실행 및 상환**에 집중하여, 필요한 프로그램을 구현하는 것을 목표로 한 프로젝트입니다.

단순 구현에서 나아가, 아래 두 가지 상황을 함께 고려했습니다.

- **구체적인 비즈니스 상황** — 실제 대출 실행 및 상환에서 발생할 수 있는 다양한 케이스와 예외 상황을 하나씩 더해가며 발전
- **기술적 문제 상황** — 여러 기술적 문제 상황을 직접 가정하고 해결

---

## 2. 요구사항 분석

> 📄 **상세 내용**: [[2] 가계 대출 상품 설명서에서 요구사항 뽑아보기 - 1](https://loan-project.tistory.com/25) · [2](https://loan-project.tistory.com/26)

은행의 **가계대출 상품 설명서**를 개발자 시각으로 분석하여 요구사항을 도출했습니다.

- **대출 금리** — 고정/변동/혼합 금리 유형별 이자 계산 방식 및 기준금리 변동 이력 관리
- **상환 방법** — 원리금 균등 / 원금 균등 / 만기 일시상환 3가지 방식과 금리 유형의 조합(6가지)에 따른 스케줄 계산
- **중도 상환 수수료** — 수수료 계산 공식 및 면제 조건(3년 경과 / 만기 90일 이내 / 대환 합산 3년 초과) 분기 처리
- **대출계약 철회권** — 철회 가능 기간 계산, 반환 금액 산정, 남용 방지 로직
- **연체** — 연체 상태 관리 및 연체 이자 산정 (상세 내용 작성 중)
- **변제 충당 순서** — 상환금 수령 시 비용 충당 우선순위 처리 (상세 내용 작성 중)
